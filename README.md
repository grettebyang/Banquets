# Banquets (WIP)

### About the Project

Banquets is a cozy game where the you work part time at a hotel setting up event spaces for weddings and dinners. Place tables, chairs, steam linens, and meet hungry dogs hiding in the shadows within the "haunted" hotel.

This is a personal project intended to portray a coming of age period of my life through a stylized lens with implied realism. It is an experimental attempt at exploring new ways to use games as a unique narrative medium.
